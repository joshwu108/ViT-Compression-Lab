# Repository guidance

This is a learning-focused research repository.

Future coding agents should:

- Follow the explicitly requested task.
- Keep additions small, readable, and easy to inspect.
- Explain unfamiliar operations when asked.
- Leave scientific and model code to the owner unless explicitly asked for help.
- Never download large assets or start training without an explicit request.
- Avoid introducing frameworks or abstractions before they are needed.
- Keep generated artifacts and secrets out of Git.
